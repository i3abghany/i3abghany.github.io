Privacy

This site sets no cookies, runs no analytics or advertising code, and loads every file from i3abghany.github.io. It stores one value in your browser, and only after you press the theme toggle. GitHub, which hosts the site, is the only party that receives information about your visit.

Browser storage

This site sets no cookies. It stores one local storage entry, theme, set to dark or light. The script theme.js writes it only when you press the light/dark toggle, and reads it on later visits to restore your chosen theme.

The entry stays on your device. Unlike cookies, which the browser attaches to every request, local storage is readable only by scripts on the page, and no script here transmits it. Since the value carries one bit and is shared by every visitor who chose the same theme, it cannot identify you.

Under Article 5(3) of the EU ePrivacy Directive, storage that is strictly necessary for a service the user explicitly requested needs no consent. The theme entry qualifies because you create it by pressing the toggle, so the site shows no cookie banner. To delete the entry, clear cookies and site data for i3abghany.github.io in your browser.

Third parties

Every file this site loads, including fonts and icons, comes from i3abghany.github.io. A font embedded from a provider such as Google Fonts would make your browser send that provider your IP address and the site you are reading. Since I host the fonts myself and inline the icons, no company other than the host learns that you visited.

Hosting

GitHub, Inc. hosts this site on GitHub Pages. Every request carries your IP address so that the server can reply, and GitHub states that it logs these addresses for security purposes. The GitHub General Privacy Statement governs that logging.

GitHub Pages gives me no visitor statistics or logs, so I receive no information about your visit.

Links out

Links to other sites, such as Google Scholar or LinkedIn, load nothing until you follow them, after which those sites' privacy policies apply. Each link carries rel="noreferrer", so your browser does not tell the destination that you came from this site.

Email

If you email me, your message is stored in my Simon Fraser University mailbox. I use it only to reply to you, and I do not add your address to any list.
